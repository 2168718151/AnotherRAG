## 保存范围

- 数据库注册表、自定义名称创建/列表/详情/改名、旧主库显式登记、整库精准删除与未完成操作恢复。
- 指定库的 TXT 列表/详情/精准删除、库内展示名称修改、保留文档身份的内容替换。
- 操作确认、强 ETag、跨进程物理库占用保护与注册库缺失存储禁止补建。
- 命令行会话先 `db use` 再连续 `query`，切库隔离 BM25/RRF 缓存，失败保留旧绑定。
- 同一次生产检索的中间态、完整最终 LLM 输入预览与不覆盖已有文件的 JSON 导出。
- API 启动绑定指定库，保留旧启动入口但遵循相同物理锁和已登记库保护。
- 中文命令规范、使用与验收文档、模块端口、工作流、代码映射与 98 个新增自动化用例。
- 保存开发前基线以来的源码、脚本、说明和记忆；此前牛客真实检索/资源测试和文件管理记录继续保留。

AIChat 故事存储、自定义页面、RAG 业务 MCP 和多轮聊天仍未启用。
现有 `shell` 保存的只是选库状态；`query` 不保存用户/助手对话，也不调用 LLM 生成。
正常生产 API 问答能力继续保留，不能把所有 HTTP 调试端口都当成无 LLM 调用。
