## 结果

133 个文档成功入库，生成 1056 个节点。128 题全部完成检索并构造 LLM 输入；
`llm_generation_calls=0`，错误日志为空。

| 阶段 | 参考答案 Hit@1 | Hit@3 | Hit@5 | 来源文档 Hit@5 |
|---|---:|---:|---:|---:|
| 向量 | 128/128 | 128/128 | 128/128 | 128/128 |
| BM25 | 126/128 | 128/128 | 128/128 | 128/128 |
| RRF | 127/128 | 128/128 | 128/128 | 128/128 |
| Rerank | 128/128 | 128/128 | 128/128 | 128/128 |

检索诊断链路延迟 P50 为 12.113 秒，P95 为 18.445 秒。该时间包括为输出中间候选而
额外执行的向量与 BM25 查询，不等同于普通 API 请求延迟。当前项目 PyTorch 为 CPU-only
（`torch.cuda.is_available() == False`），30 个候选的本地 Reranker 是主要性能风险。

## 解读边界

参考答案命中按 Unicode 宽度和空白归一化后的全文包含关系计算。128 题的问题与答案均
来自同一批源 TXT，源文件中 128/128 条参考答案均有精确文本，因此这是一组已知答案的
检索回归用例，不能据此推断独立生产问题的准确率、生成答案正确性或幻觉率。

原 Agentic RAG V1.4 的 chunk ID 与本项目分块 ID 不同，Embedding 模型与节点数也不同；
两份报告的 Hit@K 不能作为同条件性能对比。当前 Prompt 的 `source` 会包含本地绝对路径；
本次仅写入本地文件，未来若发送给外部 LLM，应先审查该字段。
