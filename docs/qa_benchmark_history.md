## 本轮范围

2026-10-13 使用 `D:\data\nowcoder_raw`，递归收集 TXT，排除 `产品`、`机械`
目录及对应类别前缀文件。本轮入选 174 个 TXT、985 组结构化 Q&A，产生 993 个节点，排除 100 个 TXT。
正文和已有答案原样读取，不修改源文件；普通正文仍按生产分块规则入库。

用户确认的测试集为原 V1.4 冻结 128 题，加 128 道新语料改写题，共 256 题。
改写题在检索前冻结于 `scripts/nowcoder_paraphrases.json`，覆盖编号 75–174 各一题，
再从 75–104 除 96、100 外各取第二题；含 114 道中文题和 14 道英文题。
改写由开发助手编写，没有调用外部 LLM API；每题标注来源文件、原问题、问答序号和参考答案。

这是一组可追溯、非原题照抄的检索测试，不是随机抽样的独立生产流量。

源文件已有答案的事实正确性未由本轮重新审定。

## 测试工作流

1. 启动隔离 Qdrant，使用独立集合、短存储路径和配套 JSON docstore。
2. 生产 TXT 解码、Q&A 解析与 `SentenceSplitter` 分块，真实 LM Studio Embedding 入库。
3. 每题仅调用一次生产 `retrieve()`：Vector / BM25 并行检索、原生 RRF、CUDA Qwen3 Reranker。
4. 将同次检索的 Top-5 节点传给 `prepare_llm_input()`，输出最终 Prompt 和 `model/messages`。
5. 统计原生检索指标、各阶段时间、内存采样，复核源文件哈希并合并历史报告。

本轮不运行 Query 改写 LLM，沿用当前生产的单 Query 配置。
不调用 DeepSeek 生成或 Yes/No 门控，不执行 HTTP API、Workflow 调度或并发压力测试。
`GenerationDisabledLLM` 的生成方法会直接报错；基准使用占位密钥，不读取真实 `api.txt` 凭据。

## 命中率口径

使用 LlamaIndex 原生 `HitRate` 和 `MRR`，以包含完整规范化参考答案的节点作为 gold IDs。
规范化只处理 Unicode NFKC、空白和大小写；相同证据出现在不同文档时接受所有对应节点。
各阶段独立统计 Hit@1、Hit@3、Hit@5 和 MRR，不使用来源文件命中冒充答案命中。
MRR 取该阶段实际候选列表，前三阶段最多 30 个节点，Rerank 最多 5 个。
JSON 的 `all_cases_rate` 只是全部用例中已确认命中的比例；旧题应使用
`answerable_rate` 和参考覆盖率，不能把 106 个未标定题纳入准确率分母。

原 128 题中仅 22 题的完整参考答案能在新语料及节点中逐字确认。
其余 106 题保留检索结果与最终输入，但不计入可判分分母：不能简单视为检索失败，
也不能视为无答案检测成功，可能存在语义等价但表述不同的答案。
新增 128 道改写题均有完整节点证据，问题经校验不原样出现在任一入选 TXT 中。

因此核心成绩为新增 128 题的完整证据命中率，原题报告需同时显示 `22/128` 参考覆盖率。
这一严格指标偏保守，语义等价但措辞不同的证据可能不计入；不等于生成答案正确率。
参考标签只供离线计分，不注入查询或 Prompt；LLM 输入中的答案来自实际检索出的上下文。

## 耗时与内存口径

- 单题 Pipeline：一次生产检索到最终 Prompt 组装，不含结果 JSON 写入和参考指标计算。
- 整轮：准备、Qdrant 启动、应用模型初始化、入库、检索器构建、256 题与输入导出。
- LM Studio 服务启动和 Embedding 装载为运行前准备，不包含在整轮计时中。
- Vector 时间包含 Embedding；RRF 时间包含并行 Vector / BM25；阶段时间不能直接相加。
- 原生回调做快照保留节点与当时分数，避免 Reranker 修改早期分数；每题复核单次阶段事件。
- 资源采样等待设置为 1 秒，实际间隔还包含测量耗时；分别记录 Python、Qdrant、LM Studio 工作集。
- 合计峰值取同一采样时刻的进程组总和，不能把各进程不同时间的峰值相加。
- RSS 为工作集，合计可能重复计算共享页；Windows Private Bytes 是提交内存，不是物理 RAM。
- 整卡显存包含其他应用，另提供本 Python 的 PyTorch allocated / reserved 峰值。
- Python Windows OS 峰值工作集另行记录，采样峰值可能漏掉两次采样之间的短暂尖峰。
